# Ejecución
El programa se ejecuta desde la terminal con el siguiente comando:
```bash
python3 problema1/src/problema1.py
```
La solucion planteada utiliza el set de datos generado ('/pruebas/set_de_datos.txt') para procesarlo y escribe los resultados de dicho procesamiento en '/pruebas/resultados_set_de_Datos.txt'

# Requisitos 
- Python 3.12.3
